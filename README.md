# 💻 Estruturas de Dados I

## 📚 Sobre o Repositório

Este repositório reúne as atividades práticas, exercícios, desafios e avaliações desenvolvidos durante a disciplina de **Estruturas de Dados I**.

Os códigos foram desenvolvidos utilizando a linguagem de programação **C**, com o objetivo de aplicar e aprimorar os conhecimentos adquiridos ao longo da disciplina.

## 📂 Organização do Repositório

O repositório está organizado nas seguintes pastas:

- **DOJO:** exercícios, desafios e problemas resolvidos durante as sessões de Coding Dojo, promovendo a prática de programação e a resolução colaborativa de problemas.
- **PROVAS:** códigos e resoluções das avaliações realizadas durante a disciplina.
- **LISTAEXERCICIOS:** listas de exercícios propostas para praticar e reforçar os conteúdos estudados.

## 🛠️ Tecnologias e Ferramentas

- **Linguagem:** C
- **Compilador:** GCC (GNU Compiler Collection)

## 🎯 Objetivos

- Desenvolver o raciocínio lógico e a capacidade de resolução de problemas.
- Praticar a implementação de algoritmos utilizando a linguagem C.
- Aplicar os conceitos estudados na disciplina de Estruturas de Dados I.
- Registrar e organizar as atividades desenvolvidas durante o semestre.
